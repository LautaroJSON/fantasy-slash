# fuentes

- **Origen:** [Google Fonts](https://github.com/google/fonts) (`ofl/cinzel`, `ofl/alegreyasans`).
- **Licencia:** SIL Open Font License 1.1 (`OFL-Cinzel.txt`, `OFL-AlegreyaSans.txt`).
- **Uso:** cartas de mejora (`docs/specs/upgrade-cards-redesign.md`). `Cinzel.ttf` es una fuente variable (eje `wght`): los títulos usan un `FontVariation` con peso 700. `AlegreyaSans-*` para las descripciones.
- **Modificaciones:** ninguna.
